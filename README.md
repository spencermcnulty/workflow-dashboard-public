## How to use

1. Edit this `README.md` directly on GitHub (click the pencil icon).
2. Fill in rows for each task.
3. Suggested **Status** values: `Not started` · `In progress` · `Blocked` · `Done`
4. Put GitHub usernames in **Owner** (e.g. `@spencermcnulty`).
5. Keep **Date Target** as `YYYY-MM-DD`.
